# Maintainers

This file lists the maintainers of etcdee, in the format used by many CNCF
projects. Maintainers have merge access and are responsible for reviewing
contributions, triaging issues, and cutting releases. See
[GOVERNANCE.md](GOVERNANCE.md) for how decisions are made and how to become
a maintainer.
