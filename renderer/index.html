etcdee

Connect to an etcd cluster to browse, edit, watch, and administer it.

Saved profiles
optional — left blank, etcdee discovers etcd on connect

A tiny broker pod (stock node:alpine image, source injected from a ConfigMap) is deployed with your kubeconfig credentials. The app tunnels to it, and it opens connections to any etcd address the cluster can reach — so put the in-cluster endpoints (service DNS, pod or node IPs) in the Endpoints field above. Access requires a bearer token stored in a cluster Secret, and only etcd ports (2379, 2380) are reachable.

Traffic is tunnelled through the Kubernetes API server, like kubectl port-forward. For a control-plane etcd (kubeadm, kind) you still need its client certificates below — on the node they live at /etc/kubernetes/pki/etcd/ca.crt and /etc/kubernetes/pki/apiserver-etcd-client.{crt,key}.
